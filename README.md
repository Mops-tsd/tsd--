# TSD Group — сайт

Пересозданный сайт группы компаний **TSD Group** (ГК «ТрансСтрой Девелопмент») —
федерального девелопера и инвестиционной группы. Все данные перенесены со старого
сайта tsr-gr.ru и обновлены по презентации 2026 года.

## Стек
Чистая статика: HTML + CSS + JS, без сборки и зависимостей.
Шрифт Manrope — self-hosted (woff2, кириллица + латиница).

## Структура
```
index.html       — Главная: hero с анимацией стройки, цифры 2026,
                   направления, проекты, карта России, цитаты, новости,
                   логотипы партнёров (бегущая строка)
about.html       — О группе: миссия, наследие (ВСТО, «Сила Сибири»),
                   ценности, таймлайн с 2008, руководство
services.html    — Направления: 4 ключевых + услуги + производство
                   (Иркутск, Белгород) + торговля AP TRADE
projects.html    — Проекты: 9 жилых/социальных + 4 промышленных, ТЭП,
                   карта городов
news.html        — Новости: 6 полных статей + архив заголовков
contacts.html    — Контакты: форма + 11 офисов
privacy.html     — Политика конфиденциальности
assets/css/      — style.css (дизайн-система), fonts.css
assets/js/       — main.js: меню, RU/EN, reveal-анимации, счётчики,
                   слайдер цитат, модалка «Заказать звонок»
assets/img/      — логотип (оригинал), логотипы партнёров, фото проектов
                   (перенесены со старого сайта, оптимизированы),
                   карта России (SVG, сгенерирована из Natural Earth)
assets/fonts/    — Manrope variable woff2
robots.txt, sitemap.xml — SEO
```

## Возможности
- Mobile-first адаптив; плавающая кнопка звонка на мобильных
- Переключатель **RU / EN** (сохраняется в localStorage)
- Hero-анимация строящегося дома (SVG: этажи, окна, кран)
- Модалка «Заказать звонок» с выбором дня и времени —
  перенос формы со старого сайта
- Слайдер цитат (реальные цитаты А. Таскаева с ПМЭФ-2026 и РБК)
- Бегущая строка логотипов партнёров (9 реальных логотипов)
- Стилизованная карта присутствия (14 городов)
- SEO: мета-теги, OG, JSON-LD Organization, sitemap, robots

## Локальный запуск
```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Деплой
Любой статический хостинг: GitHub Pages, Vercel, Netlify, nginx —
достаточно выложить содержимое каталога.

## Перед продакшеном
- Подключить реальную отправку форм (email / Telegram / CRM) —
  сейчас формы работают на фронте (показывают подтверждение)
- При появлении новых новостей — добавлять `<details class="article">`
  в news.html по образцу
