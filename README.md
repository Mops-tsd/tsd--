# TSD Group — сайт

Пересозданный сайт группы компаний **TSD Group** (ГК «ТрансСтрой Девелопмент») —
федерального девелопера и инвестиционной группы.

## Стек
Чистый статический сайт: HTML + CSS + JS, без сборки и зависимостей.
Шрифт Manrope подключается с Google Fonts.

## Структура
```
index.html       — Главная (hero c анимацией стройки, цифры, направления,
                   проекты, география, цитаты, партнёры)
about.html       — О группе (миссия, ценности, история, цитата руководства)
services.html    — Направления и компетенции
projects.html    — Проекты
contacts.html    — Контакты + форма заявки
assets/css/      — стили (дизайн-система)
assets/js/       — интерактив: меню, RU/EN, анимации, счётчики, слайдер цитат
assets/img/      — логотип / favicon (SVG)
robots.txt, sitemap.xml — SEO
```

## Возможности
- Адаптивный дизайн (mobile-first)
- Переключатель языков **RU / EN** (сохраняется в localStorage)
- Hero-анимация строящегося дома (SVG) + анимации появления и счётчики
- Блок-слайдер с цитатами
- Форма обратной связи (front-end; подключить бэкенд/почту при деплое)

## Локальный запуск
```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Деплой
Любой статический хостинг: GitHub Pages, Vercel, Netlify, nginx.
Достаточно выложить содержимое каталога.
